# Documentation

`quorum-rs` documentation follows the [Diátaxis](https://diataxis.fr) framework — four modes serving distinct user needs:

| Mode | When to read | Folder |
|---|---|---|
| Tutorial | Learning by doing — single-path lessons with expected output at every step | [tutorials/](tutorials/) |
| How-to | Goal-oriented recipes — "how do I X?" | [how-to/](how-to/) |
| Reference | Authoritative facts — API surface, types, schemas | [reference/](reference/) |
| Explanation | Understanding — why, design rationale, tradeoffs | [explanation/](explanation/) |

This tree is populated during Phase 4 of the [NSED SDK split](https://github.com/peeramid-labs/nsed/issues/357).
